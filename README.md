# sql-data-cleaning-project

## Project Overview
This project focuses on cleaning and preparing a layoffs dataset using MySQL.

The goal of this project is to:
- Remove duplicates
- Standardize data
- Handle missing values
- Prepare the dataset for analysis

---

## Tools Used
- SQL ( MySQL Workbench)
- CSV Dataset
- Data Cleaning Techniques

---

## Files Included

### Data_Cleaning.sql
Contains all SQL queries used for cleaning the dataset.

### layoffs.csv
Original dataset used in the project.

- Data Cleaning
- Data Transformation
- Handling Null Values
- Removing Duplicates
- Standardization
- Removing any Columns
